# Live Photo Maker

Turn any video or GIF into a real Apple Live Photo, free, right in your browser. No uploads, no accounts, no watermarks.

Drop in a video (MP4/MOV/WebM) or GIF, pick the cover frame, choose 1.5, 3, or 5 seconds, and download the matched pair: a .JPG and a .MOV sharing one pairing ID, stamped with the metadata Apple Photos uses to merge them into a Live Photo. Then make it an animated iMessage sticker.

Live site: https://cyroz1.github.io/live-photo-maker/
